# Checkpoint 1 — portfolio CMS design preview

Isolated local prototype, with sample content only. Does not modify or publish the portfolio.

Gallery includes sample Live, Draft and Archived cards; these labels do not represent actual published versions. Edit, duplicate, filter, search, choose 1–3 projects, reorder using accessible arrow buttons, and preview a simplified landing page. Drafts are in memory and reset on refresh. No auth, backend, analytics reporting, archive mutation or publishing is implemented. Project images and catalog are read from the sibling portfolio-development/dist folder.

Serve the parent outputs directory on localhost, then open /checkpoint-1/. Never upload this design preview as a production CMS.

Review before checkpoint 2. Later work: persisted content, actual version routes, authentication, separate draft/published revisions, permanent slug rules, archive behavior and per-version analytics.
